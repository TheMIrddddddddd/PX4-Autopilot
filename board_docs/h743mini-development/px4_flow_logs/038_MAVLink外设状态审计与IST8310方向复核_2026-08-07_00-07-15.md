### 2. 解锁策略确认（源码 + 参数实读）

- `COM_ARM_WO_GPS=1`（v1.13.3 默认，commander_params.c:298）：**无 GPS fix 不会拒绝解锁**，GPS 质量检查失败只发 warning。
- 源码路径：`src/modules/commander/Arming/PreFlightCheck/checks/ekf2Check.cpp:167-229`：仅当 `arm_without_gps=0` 时才 `Preflight Fail: GPS fix too low` 并阻止解锁。
- `SYS_HAS_GPS=1`、`EKF2_GPS_CHECK=245`（检查 fix/PDOP/垂直误差/速度误差/水平垂直漂移）、`EKF2_REQ_NSATS=6`、`EKF2_REQ_EPH=3.0m`、`EKF2_REQ_EPV=5.0m`、`EKF2_REQ_PDOP=2.5`。
- 无 GPS fix 时：`condition_global_position_valid=false`，Position/Offboard 模式不可用，仅姿态模式可解锁。

- `mavlink status` 实测两个实例：`instance #1 = USB CDC /dev/ttyACM0 mode: Config`、`instance #0 = serial /dev/ttyS4 mode: Normal`（TEL2 实例已在空 UART5 上运行，接数传即可通）。

### 4. IST8310 磁力计在线确认

- `i2cdetect -b 1` 扫到 **`0x0e`**（I2C1 = PB7/PB8，与 `rc.board_sensors` 的 `-b 1` 一致）——GPS 模块 I2C 链路已通。
- `listener sensor_mag 1`：`device_id 0x06 I2C:1 (0x0E)`，数据流新鲜（13ms），`error_count=0`，读数 `(0.187, -0.370, 0.111) gauss`，模长 ≈ 430 mGauss，健康。
- IST8310 驱动已编入固件（`CONFIG_COMMON_MAGNETOMETER=y` → Kconfig `select DRIVERS_MAGNETOMETER_ISENTEK_IST8310`），启动项 `ist8310 -X -b 1 -R 10 -q start` 已激活。

### 5. MAVLink 消息流观察

- USB 实例 mode = **Config**（mavlink_main.cpp:2080 USB 默认模式），其流表**不含 HIGHRES_IMU**——QGC MAVLink Inspector 里看不到 HIGHRES_IMU 是正常的。
- 磁力计数据通过 **SCALED_IMU** 在流（约 38 Hz），字段 `xmag/ymag/zmag` 单位 **mGauss**（`sensor_mag` 的 gauss ×1000，PX4 源码 SCALED_IMU.hpp:117-119）。
- 需要 HIGHRES_IMU 可临时开启：`mavlink stream -d /dev/ttyACM0 -s HIGHRES_IMU -r 50`。

### 6. `-R 10` 代码确认

- `ROTATION_ROLL_180_YAW_90 = 10`（src/lib/conversion/rotation.h:63），与厂商标注一致。
- 快速旋转实现（rotation.h:195-203）：`(x, y, z) → (y, x, -z)`，即先 ROLL_180 再 YAW_90 的合成。
- **`sensor_mag` 发布的是旋转补偿后的数据**（PX4Magnetometer.cpp:71-72 `rotate_3f(_rotation, ...)` 先于发布）。
- 物理结论：水平翻面（绕水平轴 180°）必然导致 z 反号——线性正交变换性质，与旋转配置无关。

### 7. 方向复核实测（用户操作，未闭环）
