## 本轮修改内容

### 1. 复核 JY901B 原始坐标转换

`src/drivers/imu/jy901b/JY901B.cpp` 的 `process_frame()` 当前先执行：

```cpp
const float x = int16_le(&frame.payload[0]);
const float y = -static_cast<float>(int16_le(&frame.payload[2]));
const float z = -static_cast<float>(int16_le(&frame.payload[4]));
```

该转换对应：

```text
JY901B 原始坐标：X 前、Y 左、Z 上（指出板面）
PX4 FRD 坐标：   X 前、Y 右、Z 下（指入板面）

(raw_x, raw_y, raw_z) -> (raw_x, -raw_y, -raw_z)
```

这一步只负责坐标系定义转换，与模块在机体上的具体安装朝向无关，因此本轮不修改该代码。

### 2. 确认当前实物为 Yaw 180 安装

当前 JY901B 相对机体在板面内掉头 180 度：

```text
模块 X：朝机尾
模块 Y：朝机身右侧
模块 Z：仍指出板面、朝上
```

绕 Z 轴旋转 180 度的安装变换为：

```text
X -> -X
Y -> -Y
Z ->  Z
```

PX4 的 `ROTATION_YAW_180` 枚举值为 `4`。`src/lib/conversion/rotation.h` 对该值的实现同样是 X/Y 取反、Z 不变。

### 3. 增加 H743mini 板级默认旋转

`boards/gjl/h743mini/init/rc.board_defaults` 新增：

```sh
# JY901B is mounted with a 180-degree yaw offset from the vehicle FRD frame.
# ROTATION_YAW_180 reverses X/Y and leaves Z unchanged.
param set-default SENS_JY901_ROT 4
```

选择板级默认参数而不是修改 `src/drivers/imu/jy901b/module.yaml` 的通用默认值，原因是 `Yaw 180` 属于当前 H743mini 实物安装关系，不是所有 JY901B 的固有方向。

### 4. 保持启动参数链路可配置

`boards/gjl/h743mini/init/rc.board_sensors` 继续使用：

```sh
if param compare SENS_JY901_EN 1
then
	jy901b -d /dev/ttyS3 -R p:SENS_JY901_ROT start
fi
```

本轮只补充注释，明确当前 H743mini 板级默认使用 `SENS_JY901_ROT=4`。JY901B 仍默认不自动启动，只有 `SENS_JY901_EN=1` 时才进入实际运行路径。

### 5. 最终坐标关系

基础 FRD 转换和 Yaw 180 安装旋转合并后：

```text
驱动基础转换： ( raw_x, -raw_y, -raw_z)
Yaw 180：       (-raw_x,  raw_y, -raw_z)
```

最终发布到 PX4 的 JY901B 加速度、角速度和磁场三轴应为：

```text
PX4 X = -JY901B raw X
PX4 Y =  JY901B raw Y
PX4 Z = -JY901B raw Z
```

气压数据不属于三轴向量，不受安装旋转影响。

## 关键输出解释

- `SENS_JY901_ROT=4`：表示传感器相对机体绕 Z 轴旋转 180 度，不是数值计算中的“减 4”。
- “Z 不变”：指模块在板面内掉头时物理 Z 轴仍指出板面；从 JY901B 的 Z 上转换到 PX4 FRD 的 Z 下时，驱动仍需对原始 Z 数据取反。
- `param set-default`：设置当前板型的默认值，不会强制覆盖用户已经保存到参数存储中的当前值。
- 如果飞控参数区此前已经保存 `SENS_JY901_ROT=0`，烧录新固件后仍需手动执行 `param set SENS_JY901_ROT 4` 和 `param save`。
- 本轮构建通过只证明代码和固件生成链路正确，尚不能代替板上三轴方向、校准和双 IMU 投票验证。

- JY901B 驱动原有 `(raw_x, -raw_y, -raw_z)` 基础转换正确，不应为了当前安装方式直接改写为板级特例。
