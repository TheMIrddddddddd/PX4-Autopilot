## 关键说明

`px_uploader.py` 握手指的是：电脑端上传工具需要在板子刚复位、PX4 bootloader 短暂停留的窗口内，和 PX4 bootloader 交换固定协议字节，确认对面是 PX4 bootloader，并且 board id、固件包信息匹配。

当前已经验证可用的是：

```text
STM32 ROM DFU + STM32CubeProgrammer CLI
```

当前暂未作为优先方式的是：

```text
make gjl_h743mini_default upload
```

原因是 PX4 uploader 与 PX4 bootloader 的握手问题还没有最终解决。

## 当前结论

当前阶段继续烧录主程序时，优先使用：

```bash
STM32_Programmer_CLI -c port=USB1 \
  -w build/gjl_h743mini_default/gjl_h743mini_default.bin 0x08020000 \
  -v
```

PX4 bootloader upload 是后期目标，不是当前必须解决的第一优先级。
