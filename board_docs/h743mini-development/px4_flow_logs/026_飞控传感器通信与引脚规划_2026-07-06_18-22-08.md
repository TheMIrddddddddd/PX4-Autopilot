## 概念

### PX4 对 IMU 的使用方式

PX4/EKF2 的主线不是直接使用外部模块输出的姿态角，而是使用传感器测量量。

主链路是：

```text
传感器驱动
 -> sensor_accel / sensor_gyro / sensor_mag / sensor_baro
 -> sensors / vehicle_imu / sensor selection
 -> EKF2
 -> vehicle_attitude
```

因此：

- `ICM42688P` 作为主 IMU，提供主 `accel` 与主 `gyro`。
- `JY901B` 的角度、四元数只适合作参考和日志对照，不应直接覆盖 PX4 的 `vehicle_attitude`。
- `JY901B` 若要进入 EKF2 链路，需要先解析串口帧，再按 PX4 话题发布加速度、角速度、磁场和气压。

### 主 IMU 与副 IMU 的关系

本轮不采用“两个 IMU 每个采样点直接平均”的思路。

更合适的阶段性策略是：

```text
ICM42688P：主 accel / 主 gyro，高优先级
JY901B：副 accel / 副 gyro，先低优先级或仅日志对比
```

后续如果需要多 IMU 冗余，再进入 PX4 `sensor_selection`、`CAL_ACCx_PRIO`、`CAL_GYROx_PRIO`、`EKF2_MULTI_IMU` 等机制，而不是在驱动里手写简单平均。

### 主磁力计选择

`IST8310` 可以作为主磁力计，且比 JY901B 内置磁力计更适合做长期主磁力计。

原因：

- GPS 模块可以安装在机身上方，更容易远离电机、电调、电源线和大电流线。
- JY901B 作为 IMU / 姿态模块通常更适合靠近机体中心和刚性安装，而磁力计更需要远离磁干扰，这两个安装需求并不完全一致。

## 本轮规划内容

### 1. ICM42688P 主 IMU

通信方式：`SPI2`

| ICM42688P 信号 | H743mini 引脚 | STM32 外设 | 说明 |
|---|---|---|---|
| `VCC` | `3.3V` | 电源 | 使用 3.3V，不建议 5V |
| `GND` | `GND` | 地 | 必须与飞控共地 |
| `SCK` | `PD3` / `P2-38` | `SPI2_SCK` | 当前 `board.h` 已保留 SPI2 定义，后续需启用 SPI2 |
| `MISO` | `PC2` / `P1-6` | `SPI2_MISO` | 当前 `board.h` 已保留 SPI2 定义 |
| `MOSI` | `PC3` / `P1-7` | `SPI2_MOSI` | 当前 `board.h` 已保留 SPI2 定义 |
| `CS` | `PE4` | GPIO | 新规划的片选脚 |
| `INT` / `DRDY` | `PE6` | GPIO interrupt | 数据就绪中断 |

关键取舍：

- 当前 `spi.cpp` 里 V6C 遗留的 ICM42688P CS 是 `PC13`，但 `PC13` 当前已经作为板级 LED 使用，因此后续必须改掉。
- 原 `SPI1 PA5/PA6/PA7` 方案中 `PA6` 未从 P1/P2 排针引出，不适合当前 2.54 母座载板；改用排针完整引出的 `SPI2 PC2/PC3/PD3`。
- `PE4` / `PE6` 都在外部排针上，适合作 ICM42688P 的 CS 与 DRDY。
- 第一阶段只启用 ICM42688P，不同时恢复 BMI055。

### 2. GPS + IST8310

GPS 通信方式：`USART2`

IST8310 通信方式：`I2C1`

| 模块信号 | H743mini 引脚 | STM32 外设 | 说明 |
|---|---|---|---|
| GPS `VCC` | `5V` 或 `3.3V` | 电源 | 按模块要求供电，确认信号电平 |
| GPS `GND` | `GND` | 地 | 必须与飞控共地 |
| GPS `TX` | `PA3` | `USART2_RX` | GPS 发，飞控收 |
| GPS `RX` | `PA2` | `USART2_TX` | 飞控发，GPS 收 |
| IST8310 `SCL` | `PB8` | `I2C1_SCL` | GPS 模块外置罗盘 |
| IST8310 `SDA` | `PB7` | `I2C1_SDA` | GPS 模块外置罗盘 |

关键取舍：

- `USART1 PA9/PA10` 已用于 CH340/NSH 调试，不给 GPS。
- `USART6 PC6/PC7` 保留给 RCIN / CRSF。
- `UART5 PC12/PD2` 与 TF 卡 SDMMC1 冲突，不使用。
- 当前 `board.h` 中 `USART2_TX` 仍为 `PD5`，后续接 GPS 时需要改成 `PA2` 对应的 `GPIO_USART2_TX_1`。

### 3. JY901B 副 IMU / 气压计 / 姿态参考

通信方式：`UART4`

| JY901B 信号 | H743mini 引脚 | STM32 外设 | 说明 |
|---|---|---|---|
| `VCC` | `3.3V` | 电源 | 优先 3.3V，减少电平风险 |
| `GND` | `GND` | 地 | 必须与飞控共地 |
| `TX` | `PH14` | `UART4_RX` | JY901B 发，飞控收 |
| `RX` | `PH13` | `UART4_TX` | 飞控发，JY901B 收 |

关键取舍：

- JY901B 支持串口和 I2C，本轮选择串口。
- 不使用 I2C2，因为 I2C2 已用于 BL24C16F EEPROM，且 JY901B 默认 I2C 地址容易和 `0x50~0x57` EEPROM 地址段冲突。
- 不优先用 `PA0/PA1`，因为此前规划中这两个脚可能受按键相关电路影响；`PH13/PH14` 更干净。
- 第一阶段先做串口读帧和日志对比，不直接参与姿态控制。

5. 修改 GPS/IST8310：
   - `USART2_TX` 从 `PD5` 改为 `PA2`。

   - 启用 `UART4 PH13/PH14`。
   - 先做最小串口读帧验证。

|---|---|---|---|

## 当前结论

- `ICM42688P` 确认为当前 H743mini 的主 IMU 方向。
- `ICM42688P` 只提供加速度计和陀螺仪，不提供磁力计或气压计。
- `IST8310` 可以作为主磁力计，且比 JY901B 内置磁力计更适合作长期主磁力计。
- `JY901B` 可以提供加速度、角速度、磁场、气压/高度和姿态角，但第一阶段应作为副传感器和参考模块，不应直接覆盖 PX4 的 `vehicle_attitude`。
- `JY901B` 选择 UART4 `PH13/PH14`，不使用 I2C。
- 后续真正接入前，需要先完成 ICM42688P 主 IMU 适配，让 EKF2 获得可靠主 accel / gyro。

## 常见坑

- 不要把 JY901B 输出的角度或四元数直接当成 EKF2 主输入。
- 不要把两个 IMU 的数据在驱动层简单平均；PX4 有传感器选择、优先级和多 EKF 机制。
- 不要继续使用 V6C 遗留的 `PC13` 作为 ICM42688P 片选，因为当前 `PC13` 已用于 LED。
- 不要把 JY901B 接到 I2C2，避免和 BL24C16F EEPROM 地址段冲突。
- 不要把 GPS 接到 USART1，USART1 已经用于 CH340/NSH 调试。
- 不要把 GPS 接到 UART5 的 `PC12/PD2`，这组脚与 TF 卡 SDMMC1 冲突。
- 磁力计安装位置比“能读到数据”更重要，应远离电机、电调、电源线和大电流线。

## 调试方法

### ICM42688P

1. 确认 `3.3V`、`GND`、`PC2/PC3/PD3`、`PE4`、`PE6` 接线，其中 `PD3` 对应 `P2-38`。
2. 上电后检查 `dmesg` 中是否有 ICM42688P probe / start 信息。
3. 用 `listener sensor_accel` 和 `listener sensor_gyro` 验证数据。
4. 用 `listener vehicle_imu` 验证 `VehicleIMU` 是否生成。

### IST8310

1. 接 GPS 模块的 `SCL/SDA` 到 `PB8/PB7`。
2. 执行 `i2cdetect -b 1`，优先确认是否能看到 `0x0c`。
3. 启动 `ist8310` 后用 `listener sensor_mag` 验证。
4. 校准罗盘并确认安装方向。

### JY901B

1. 先用 USB-TTL 或逻辑分析仪确认 JY901B 输出帧和波特率。
2. 再接到 H743mini `UART4 PH13/PH14`。
3. 先做最小串口读帧，不急着发布 PX4 传感器话题。
4. 解析稳定后再逐步发布 `sensor_accel`、`sensor_gyro`、`sensor_baro`、`sensor_mag`。

## 复盘要点

本轮关键不是新增一个传感器，而是把飞控传感器体系拆成了三个层次：

1. 主飞控闭环必须先有可靠的主 IMU：`ICM42688P`。
2. 航向来源优先用外置主磁力计：`IST8310`。
3. JY901B 这种带 MCU 的十轴模块可以作为副传感器和参考，但不能把它的姿态角直接当成 PX4 EKF2 的结果。

这样规划后，后续每个外设都有独立验证路径，错误来源不会混在一起。
