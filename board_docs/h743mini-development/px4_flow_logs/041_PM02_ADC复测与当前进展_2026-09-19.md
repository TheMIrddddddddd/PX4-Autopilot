记录当前 H743mini 自定义板的总体测试进展，并单独收口 PM02 电池电压/电流 ADC 的实际状态。当前测试阶段使用 USB MAVLink/NSH，最近一次明确的供电状态为：**未接电池，仅 USB 供电**。

## 4. PM02 ADC 实测结果

### 4.1 当前供电条件

当前明确状态为：

```text
电池：未接入
供电：USB
```

因此 PC4/PC5 没有来自 PM02 的有效模拟信号，属于悬空或无定义电平。当前状态不能用于判断电池分压比例、电流零点或 ADC 硬件精度。

### 4.2 MAVLink/NSH 输出

最近一次输出：

```text
adc_report:
  resolution: 65536
  v_ref: 3.3000
  channel_id: [4, 8, 20, ...]
  raw_data: [32768, 65535, 65535, ...]
```

```text
battery_status:
  voltage_v:          59.9997
  voltage_filtered_v: 59.9997
  current_a:           0.0000
  current_filtered_a: 21.5986
  connected:           True
  cell_count:          3
```

```text
system_power:
  voltage5v_v:     0.0000
  usb_connected:   0
  usb_valid:       0
  brick_valid:     1
  servo_valid:     1
```

`board_adc test` 能持续输出并显示 `ADC test successful`，但这只证明 ADC 采样循环和话题发布没有超时，不代表输入电压值正确。测试中 PC5 通道 8 多次为 `65535`，PC4 通道 4 在 `0`、`32768` 间变化，温度通道 20 为 `65535`。

### 4.3 数值解释

当前参数为：

```text
BAT1_V_DIV       = 18.1820
BAT1_A_PER_V     = 36.3640
BAT_V_OFFS_CURR  = 0.0000
```

换算关系为：

```text
ADC 输入电压 = raw_data / 65536 × 3.3 V
电池电压     = ADC 输入电压 × BAT1_V_DIV
```

所以：

```text
raw_data = 65535  -> ADC 输入约 3.3 V -> 电池显示约 60 V
raw_data = 32768  -> ADC 输入约 1.65 V -> 电池显示约 30 V
PC5 实测 0.66 V  -> 期望 raw_data 约 13107
```

对于未接 PM02、输入悬空的 USB 基线，`60 V`、`30 V`、`60 A` 等都是假电池状态，不能作为真实电池电压或电流使用。`connected=True` 是模拟电压超过 `BOARD_ADC_OPEN_CIRCUIT_V=5.6 V` 后由 PX4 电池模块计算出来的结果，不代表物理上确实插入了电池。

如果在**已经接入电池和 PM02**时仍然出现 `PC5 实测约 0.66 V` 但 `raw_data=65535`，则问题仍未解决，需要继续检查 PM02 VOLT 输出、PC5 走线/焊点、ADC 通道选择和 H7 ADC 寄存器状态；不能通过修改 `BAT1_V_DIV` 掩盖问题。

## 5. 当前结论和安全边界

结论：ADC 驱动能够运行并发布数据，但 PM02 电压/电流测量目前仍不能验收。当前 USB-only 的满量程或半量程读数只能说明未接入的模拟输入处于浮空/无定义状态，不能据此判断 ADC 芯片损坏。

在 PM02 ADC 闭环前：

- 不依据 `battery_status.voltage_v` 判断真实电池电量。
- 不依据当前 `connected=True` 作为电池已接入证据。
- 不修改 `BAT1_V_DIV`、`BAT1_A_PER_V` 或 `BAT_V_OFFS_CURR` 来消除假读数。
- 接电调和电机测试时保持拆桨，并把电池电压状态视为未验收项。

## 6. 下一步验证方法

接入电池和 PM02 后，保持螺旋桨拆除，按以下顺序复测：

1. 确认电池正负极接在 PM02 的电池输入端，PC5 只接 PM02 的 VOLT 缩放输出，不能把电池正极直接接到 PC5。
2. 上电后用万用表测量 PM02 VOLT 输出和飞控 PC5 对地电压。
3. 通过 MAVLink NSH 执行：

```sh
listener adc_report 1
listener battery_status 1
listener system_power 1
board_adc test
```

4. 若 PC5 约为 `0.66 V`，应看到电压通道原始值约 `13107`；若仍为 `65535`，继续做 PC5 走线/短路/通道映射排查。
5. PC4 的电流零点必须在确认 PM02 CURRENT 输出电压后，再单独设置 `BAT_V_OFFS_CURR`；不能用悬空输入校准。

在没有 PM02 的阶段，如需避免 QGC 显示假电池状态，可临时设置 `BAT1_SOURCE=-1`；接入并验证 PM02 后再恢复为 `0`。
