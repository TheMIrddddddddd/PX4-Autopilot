# 006 ST-Link 探针识别成功 2026-06-27 12:11:00

## 概念
本次进展是确认 Ubuntu Linux 下 STM32CubeProgrammer 已经能识别 ST-Link 探针。这个阶段只代表电脑识别到了调试器，还不代表已经连接到 STM32H743 目标芯片。

## 代码/流程
### 已执行命令
```bash
STM32_Programmer_CLI -l
```

### 关键输出
```text
ST-Link Probe 0 :
   ST-LINK SN  : 35003800060000303257514E
   ST-LINK FW  : V2J29S7
   Access Port Number  : 3
```

### 当前判断
- STM32CubeProgrammer 安装有效。
- udev 规则已经基本生效，普通用户可以看到 ST-Link。
- 下一步需要测试 ST-Link 是否能通过 SWD 连接到 STM32H743IIT6 芯片。

## 常见坑
- `STM32_Programmer_CLI -l` 能看到 ST-Link，不等于 SWD 接线正确。
- 如果后续连接芯片失败，优先检查 GND、SWDIO、SWCLK、NRST、目标板供电和 BOOT0 状态。
- 目标板需要有稳定 3.3V，ST-Link 也需要识别目标电平。

## 调试方法
下一步连接测试建议：

```bash
STM32_Programmer_CLI -c port=SWD mode=UR reset=HWrst freq=4000
```

如果失败，可以降低频率：

```bash
STM32_Programmer_CLI -c port=SWD mode=UR reset=HWrst freq=1000
```

## 复盘要点
- 当前已经跨过“Linux 识别 ST-Link”这一关。
- 下一关是“ST-Link 能否连接目标芯片”。
- 连接芯片成功后再进行全片擦除和双地址烧录。
