
## 常见坑
- 只安装软件还不够，Linux 下 ST-Link 访问经常还需要 udev 规则。
- 如果 ST-Link 已经插着，安装 udev 后建议拔插一次 ST-Link。
- 如果普通用户仍然无法访问 ST-Link，可以先尝试重新插拔，再检查 `STM32_Programmer_CLI -l`。

## 调试方法
后续连接 ST-Link 后，先执行：

```bash
STM32_Programmer_CLI -l
```

如果能看到 ST-Link，再执行连接测试：

```bash
STM32_Programmer_CLI -c port=SWD mode=UR
```

后续计划烧录命令：

```bash
cd /home/gjl/PX4-Autopilot

STM32_Programmer_CLI -c port=SWD mode=UR -e all

STM32_Programmer_CLI -c port=SWD mode=UR \
  -w build/gjl_h743mini_bootloader/gjl_h743mini_bootloader.bin 0x08000000 \
  -v

STM32_Programmer_CLI -c port=SWD mode=UR \
  -w build/gjl_h743mini_default/gjl_h743mini_default.bin 0x08020000 \
  -v -rst
```
