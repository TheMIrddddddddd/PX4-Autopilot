## 常见坑

当前日志里的错误大多来自“仍然沿用 V6C 外设配置，但最小系统板没有这些外设或还没有适配”。

主要错误含义：

- `PX4_MTD failed to initialize`：V6C 配置尝试初始化外部 MTD/FRAM/EEPROM 类存储，但当前板级外设还没适配。
- `formatting /dev/mmcsd0` 后 `format failed`：PX4 尝试使用 SD 卡，但当前 SD 卡未接入、未识别或引脚未适配。
- `param import failed`：参数默认想从 `/fs/microsd/params` 读取，但 SD 卡不可用。
- `dataman start failed`：任务/航点等数据管理依赖存储，当前存储不可用。
- `bmi055/icm42688p/ms5611/ist8310 no instance started`：V6C 默认传感器没有在当前最小系统板上响应。
- `ekf2 start failed`：IMU/气压计/磁力计等关键传感器缺失，EKF 无法启动。
- `Missing FMU SD Card`：没有可用 SD 卡。
- `system power unavailable`：电源监测/ADC 配置还没有适配当前硬件。

这些错误说明下一阶段应该收敛启动项，而不是继续照搬完整 V6C 配置。

## 调试方法

QGroundControl 中看日志：

- 普通状态消息：点击左上角 `Not Ready` 附近的消息图标。
- 命令行日志：`Analyze Tools / 分析工具 -> MAVLink Console`，输入 `dmesg`。
- 飞行日志：`Analyze Tools / 分析工具 -> Log Download`，但当前 SD 卡未适配，可能没有可下载日志。

CH340 串口控制台：

- USART1 控制台当前应为 `115200 8N1`。
- 如果电脑没有出现 `/dev/ttyUSB0`，说明 CH340 口没有被系统识别。
- 如果出现 `/dev/ttyUSB0` 但没有输出，再检查 USART1 控制台是否和 GPS1 `/dev/ttyS0` 配置冲突。

## 复盘要点

当前阶段已经完成：

- 固件能启动。
- USB CDC 可用。
- QGC 能连接。
- NSH 能进入。
- 启动日志能读取。

下一阶段建议重点：

1. 清理 V6C 默认外设启动项，先保留最小可运行系统。
2. 处理 USART1 控制台和 GPS1 `/dev/ttyS0` 的角色冲突。
3. 临时关闭未接入的传感器、SD、MTD、UAVCAN、PX4IO 等启动项。
4. 保留 QGC USB MAVLink 和 NSH 调试能力。
5. 再开始逐个外设验证：SD 卡、IMU、气压计、磁力计、GPS、电源 ADC。
