## 本轮修改内容

### 1. 将 `rc_input` 编入 H743mini 固件

文件：

```text
boards/gjl/h743mini/default.px4board
```

新增：

```text
CONFIG_DRIVERS_RC_INPUT=y
```

作用：把 PX4 RC 输入驱动编入 `gjl_h743mini_default` 固件。该驱动负责读取接收机串口、扫描并解析 PPM、SBUS、DSM、CRSF 等协议；本项目使用其中的 CRSF 路径。

### 2. 指定 USART6 为默认 RC 串口

文件：

```text
boards/gjl/h743mini/src/board_config.h
```

新增：

```c
/* USART6 PC6/PC7 is used for ELRS/CRSF receiver input. */
#define RC_SERIAL_PORT                         "/dev/ttyS5"
#define BOARD_SUPPORTS_RC_SERIAL_PORT_OUTPUT
```

作用：

- `RC_SERIAL_PORT` 让 `rc_input` 在没有额外 `-d` 参数时默认打开 `/dev/ttyS5`。
- `BOARD_SUPPORTS_RC_SERIAL_PORT_OUTPUT` 允许同一串口向 ELRS 接收机发送 CRSF 遥测数据。
- 当前串口排列中，UART5/TEL2 已使用 `/dev/ttyS4`，USART6 对应 `/dev/ttyS5`。
- 原 `PX4IO_SERIAL_DEVICE "/dev/ttyS4"` 属于已关闭 PX4IO 的遗留定义，本轮没有修改；`CONFIG_DRIVERS_PX4IO` 仍为关闭状态。

## 关键输出解释

- `UART device: /dev/ttyS5`：证明 `RC_SERIAL_PORT` 生效，USART6 设备能够被 `rc_input` 正常打开。
- `RC state: searching for signal: CRSF`：证明驱动已经运行并进入 CRSF 扫描状态。
- `UART RX bytes: 12`：当前未接接收机，少量字节不能视为有效 CRSF 帧，可能来自悬空 RX 线噪声。
- `publish interval: 0 events`：当前没有收到并发布有效遥控通道帧，符合接收机尚未接入的条件。
- 后续验收不能只看 RX 字节增长，必须看到 `RC state: found: CRSF` 和非零发布事件。

## 当前接线规划

接收机到货后保持以下接线：

| ELRS 接收机 | H743mini | 功能 |
|---|---|---|
| `TX` | `PC7 / USART6_RX` | 接收机向飞控发送 CRSF 数据 |
| `RX` | `PC6 / USART6_TX` | 飞控向接收机回传 CRSF 遥测 |
| `5V` | 稳压 `5V` | 接收机供电，禁止直接接电池正极 |
| `GND` | `GND` | 飞控和接收机必须共地 |

接线必须在飞控断电状态下完成。接收机的 TX/RX 命名以接收机自身方向为准，因此必须交叉连接。

## 下一阶段任务和目标

目标：遥控器和 ELRS 接收机到货后，完成 CRSF 接线、绑定、通道输入与遥测回传的完整板级验证。

优先任务：

1. 飞控断电，核对接收机输入电压和焊盘定义。
2. 按 `TX -> PC7`、`RX -> PC6`、`5V -> 稳压 5V`、`GND -> GND` 接线。
3. 先完成 Radiomaster Pocket 与 ELRS 接收机的绑定确认。
4. 上电后执行 `rc_input status`，确认状态变为 `RC state: found: CRSF`。
5. 检查 `publish interval` 是否产生非零事件，并查看 `listener input_rc`。
6. 在 QGroundControl 中检查各遥控通道方向、范围和校准结果。
7. 验证断开遥控器后的 failsafe 行为。
8. 检查 `CRSF Telemetry: yes`，确认飞控向接收机的遥测回传路径有效。

验收标准：

- `rc_input status` 显示 `/dev/ttyS5` 且 `RC state: found: CRSF`。
- `listener input_rc` 能随摇杆和开关动作持续更新。
- 通道数量、最小值、中值、最大值和方向正确。
- 遥控器断开后 PX4 能识别 RC signal lost/failsafe。
- `CRSF Telemetry: yes`，遥控器侧能够看到有效飞控遥测数据。
- 整个验证期间 USART6 不与 UART5/TEL2、GPS1、TF 卡、PWM 和其他已规划外设冲突。
