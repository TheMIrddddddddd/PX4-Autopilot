# 040 外设闭环与 Direct PWM 波形测试

时间：2026-09-18

## 1. 本轮目标

在 039 日志之后补充当前已经完成的外设闭环测试，重点记录：

1. GPS 有星定位和静态数据质量。
2. GPS 模块内置 IST8310 的航向连续性。
3. 气压计静止稳定性以及 EKF2 的高度来源。
4. WiFiLink/TEL2 的 MAVLink 高速 IMU 数据流。
5. 六路 Direct PWM 的 400 Hz / 50 Hz 波形。
6. PM02 电池 ADC 当前仍未闭环的原因。

本轮没有修改 PX4 源码；PWM 测试只使用参数和启动后的运行状态验证。

## 3. 本轮已完成测试

### 3.1 GPS 有星定位

通过 MAVLink/QGC 查看 `GPS_RAW_INT` 和 `sensor_gps`，已观察到：

- `fix_type = 3`，达到 3D fix。
- 可见卫星数从约 7 颗增加到约 10 颗。
- `h_acc` 约从 3 m 收敛到 2.2 m 左右。
- `v_acc` 约从 4.2 m 收敛到 2.6 m 左右。
- `lat/lon` 连续更新，静止放置时没有持续发散。

结论：GPS 串口、UBX 解析和室外基础定位正常。`h_acc`、`v_acc` 是定位误差估计，不是飞控的真实高度值；后续仍需在飞行器安装位置完成遮挡、移动和电源干扰复测。

### 3.2 GPS 内置 IST8310 航向基础测试

当前两个磁力计均在线，`sensors status` 显示 GPS 模块内置 IST8310 为高优先级主磁力计，JY901B 内置磁力计为低优先级备用磁力计。

机头保持水平，分别指向北、东、南、西时记录的 `vehicle_attitude.yaw`（弧度）约为：

| 方向 | yaw（rad） | 期望范围 |
|---|---:|---:|
| 北 | -0.164 | 接近 0 |
| 东 | 1.531 | 接近 +π/2 |
| 南 | 3.047 | 接近 +π |
| 西 | -1.415 | 接近 -π/2 |

结论：航向方向和连续性基本正确，没有观察到 90°/180°固定跳变；`-π` 到 `+π` 的回绕属于正常表示方式。磁力计最终的电机、电调和电源线干扰测试仍未完成。

### 3.3 气压计静止测试

飞控静止观察约 5 分钟，关键状态包括：

```text
EKF2_HGT_MODE = 0
cs_baro_hgt   = True
cs_gps_hgt    = False
vehicle_air_data.baro_pressure_pa ≈ 101130 Pa
vehicle_air_data.baro_alt_meter   ≈ 16.2 m（相对起飞点基准）
```

结论：气压计数据稳定，当前 EKF2 高度来源为气压计。PX4 使用的是以起飞时气压高度为基准的相对高度，不应把 `baro_alt_meter` 直接理解为精确海拔；GPS 高度当前未作为 EKF2 主高度来源。

### 3.4 WiFiLink/TEL2 MAVLink 数据流

WiFiLink 通过 UART5 `PB13/PB12`、`/dev/ttyS4` 接入 QGC 后，执行：

```sh
mavlink stream -d /dev/ttyS4 -s HIGHRES_IMU -r 50
```

QGC 可以看到 `HIGHRES_IMU`，IMU 数据流正常。

结论：UART5/TEL2 的 MAVLink 链路和高频 IMU 消息均正常。当前 `mavlink stream` 是运行时命令，重启后不一定自动保留；“每次上电自动输出 50 Hz”属于后续启动脚本/参数收口事项，不是传感器故障。

### 3.5 六路 Direct PWM 波形

源码映射为：

| 输出 | 引脚 | 定时器 | 定时器组 |
|---|---|---|---|
| PWM1–4 | PA15、PB3、PB10、PB11 | TIM2_CH1–CH4 | 组 0 |
| PWM5–6 | PB4、PB5 | TIM3_CH1–CH2 | 组 1 |

初始运行状态：

```text
通道 1–4：alternative rate 400 Hz，输出值 900 us
通道 5–6：default rate 50 Hz，但输出值 0 us
channel group 0：1 2 3 4
channel group 1：5 6
```

原因确认：当前只有 `/dev/pwm_output0`，没有 `/dev/pwm_output1`；`PWM_MAIN_OUT=1234` 只启用了前四路，5、6 路虽然存在 50 Hz 定时器组，但没有有效脉宽，因此示波器看不到脉冲。另外，本固件 `pwm` 帮助文本中的 `pwm test` 是残留示例，实际执行会返回 Usage，不能用它给通道写入测试脉宽。

为验证 TIM3/PB4/PB5 硬件链路，临时设置：

```sh
param set PWM_MAIN_DIS5 1500
param set PWM_MAIN_DIS6 1500
param save
reboot
```

设置后确认 5、6 路出现 50 Hz 波形；1–4 路已经观察到 400 Hz 波形。

结论：

- TIM2 的 1–4 路 400 Hz 输出正常。
- TIM3 的 5–6 路 50 Hz 输出正常。
- PB4/PB5、TIM3、PWM 分组和脉宽生成链路已通过基础波形验证。
- `PWM_MAIN_DIS5/6=1500` 只是让未解锁状态产生可测脉冲的台架测试方法，不等于最终的 mixer/执行器输出配置；正式接 ESC 或电机前必须恢复安全停机值，或完成正确的输出映射。

### 3.6 PM02 电池 ADC 状态

PM02 电池检测暂不作为本轮完成项。当前实测：

```text
PC5 对地实测：约 0.66 V
adc_report raw_data[电压通道]：65535
battery_status.voltage_v：约 60 V
```

按 `raw_data/resolution/v_ref` 换算，0.66 V 应约为 13107 counts，而不是 65535 counts。因此当前 ADC 读数与实测电压不一致，电池电压/电流状态不能用于解锁和飞行判断，后续单独排查 ADC 通道、板级采样路径和驱动映射。

### 3.7 ELRS/CRSF RF 丢失与恢复

正常链路基线：

```text
rc_input：found: CRSF
UART RX bytes：持续增加
CRSF Telemetry：yes
channel_count：16
rc_failsafe：False
rc_lost：False
vehicle_status.rc_signal_lost：False
```

关闭遥控器发射端并等待约 5 秒后：

```text
rc_input：searching for signal: CRSF
vehicle_status.rc_signal_lost：True
vehicle_status.failsafe：False
commander：STANDBY / STAB
```

重新打开遥控器后：

```text
rc_input：found: CRSF
CRSF Telemetry：yes
channel_count：16
rc_failsafe：False
rc_lost：False
vehicle_status.rc_signal_lost：False
commander：STANDBY / STAB
```

说明：断链期间 `listener input_rc` 可能仍显示最后一次缓存的输入帧，因此不能仅凭其中旧帧的 `rc_lost` 字段判断当前状态；应结合 `rc_input status` 和 `vehicle_status.rc_signal_lost` 判断。

结论：ELRS/CRSF 的正常接收、RF 丢失检测和恢复均通过；全过程未解锁、未接电机。

已完成：

- GPS 有星定位基础测试。

- 气压计约 5 分钟静止稳定性测试。
- WiFiLink/TEL2 的 MAVLink `HIGHRES_IMU` 数据流测试。
- PWM1–4 的 400 Hz 波形测试。
- PWM5–6 的 50 Hz 波形测试。
- ELRS/CRSF 16 通道接收、RF 丢失检测和恢复测试。
- ICM42688P 主 IMU、JY901B 备 IMU 的校准、方向、主备优先级和静止零漂测试（详见 039）。

尚未完成或不作为通过项：

- PM02 电压/电流 ADC 仍不可信，暂缓。
- PWM5/6 的正式输出映射、mixer/Actuator Test 和接电调前验收未完成。
- 磁力计靠近电机、电调、电池线时的抗干扰测试未完成。
- TEL2 的 `HIGHRES_IMU 50 Hz` 自动启动配置未固化。

## 下一阶段任务和目标

目标：在不接电机、不装桨的前提下，完成剩余的安全功能闭环，再决定是否修改 PWM 的正式输出映射。

优先任务：

1. **TEL2 MAVLink 自动流**：重启后确认 UART5 `/dev/ttyS4` 是否仍有 HEARTBEAT、ATTITUDE；如只有手工执行 `mavlink stream` 才有 `HIGHRES_IMU`，再单独收口启动脚本或流参数。
2. **Direct PWM 正式映射方案确认**：先明确 PWM5/6 是电机/电调还是舵机。电机输出不能长期使用 1500 us 的解锁前脉宽；舵机输出则需按舵机规格确定 50 Hz 和中位值。确认用途后再配置 `PWM_MAIN_OUT`、rate group 和 mixer。
3. **磁力计电源/电机干扰测试**：在 PWM/电调接入但不装桨的条件下，分别观察 `sensor_mag` 模长、航向和 `estimator_status_flags`；PM02 ADC 未修复前，不把电池电压状态作为通过条件。
4. **PM02 ADC**：用户决定继续时，再按“万用表采样点 → `adc_report` 原始计数 → `battery_status` 缩放值”的顺序排查，不能仅修改分压参数掩盖通道错误。

验收标准：

- RF 断链后至少能观察到 `rc_signal_lost=True`，恢复后清除该标志；具体 commander failsafe 动作需在明确参数和安全条件后单独验证，本轮未解锁因此不将其计为已验证。
- TEL2 重启后能按预期输出需要的 MAVLink 消息。
- PWM5/6 的用途、停机脉宽、频率和 mixer 映射明确后，才允许接 ESC；接 ESC 前仍必须无桨验证。
- 磁力计在静态和电源/电机干扰条件下没有明显跳变或 `mag fault`。
