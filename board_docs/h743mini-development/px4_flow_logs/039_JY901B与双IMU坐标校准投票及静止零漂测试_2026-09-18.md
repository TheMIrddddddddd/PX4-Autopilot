# 039 JY901B 与双 IMU 坐标、校准、投票及静止零漂测试

时间：2026-09-18

## 1. 本轮目标

在 H743mini 上完成以下验证：

1. 验证 JY901B UART4 驱动和四类传感器输出。
2. 对比 JY901B 与 ICM42688P 的三轴方向，确认之前的旋转判断。
3. 完成 QGroundControl 加速度计、陀螺仪和磁力计校准后的参数检查。
4. 设置 ICM42688P 为主 IMU、JY901B 为备 IMU，清理重复校准槽。
5. 对两颗 IMU 做约 30 分钟静止零漂观察。
6. 更新板级默认旋转参数并重新构建、更新固件。

## 2. 当前硬件与接口

| 设备 | 接口 | PX4 设备/数据 |
|---|---|---|
| ICM42688P | SPI2，-R 0 | 主 accel/gyro |
| JY901B | UART4，/dev/ttyS3，115200 8N1 | 备 accel/gyro、磁力计、气压计 |
| GPS 模块内置 IST8310 | I2C1，地址 0x0e | 主磁力计候选 |

JY901B 驱动启动命令：

    jy901b -d /dev/ttyS3 -R p:SENS_JY901_ROT start

## 3. 已完成测试

### 3.1 JY901B 通信和数据发布

jy901b status 实测结果：

- 加速度、陀螺仪、磁力计和气压数据均能发布，频率约 200 Hz。
- 读错误、校验错误和超时为 0。
- 最终状态无未知帧，最近帧时间正常。
- sensor_accel、sensor_gyro、sensor_mag、JY901B 气压数据链路均已接入 PX4 标准传感器框架。

结论：JY901B UART4 接线、协议解析和 PX4 发布链路正常。

### 3.2 三轴方向 A/B 对比

使用相同的物理动作分别观察 JY901B 和 ICM42688P：

- 机头朝地：ICM42688P 的 xacc 约为 -9，JY901B 在错误旋转参数下曾显示相反符号。
- 机体向左滚转 90°：ICM42688P 的 yacc 约为 +9，JY901B 在 -R 4 下显示相反符号。
- -R 0 与 ICM42688P 的三轴方向一致。
- -R 4（ROTATION_YAW_180）会再次把 X/Y 方向反过来，确认不适用于当前实物安装。

最终结论：

    JY901B 基础坐标转换：保留 (raw_x, -raw_y, -raw_z)
    当前 H743mini 实物旋转：SENS_JY901_ROT = 0

没有修改通用 JY901B 驱动的基础坐标转换，只修改板级默认参数：

- boards/gjl/h743mini/init/rc.board_defaults
- boards/gjl/h743mini/init/rc.board_sensors

### 3.3 QGroundControl 校准

已完成并检查：

- 加速度计六面校准。
- 陀螺仪静止校准。
- 磁力计校准流程。
- 校准后的设备 ID 与传感器槽对应关系。

校准原则保持不变：两个 IMU 作为两个独立传感器分别校准；不能用一个 IMU 的校准数据替代另一个 IMU。

### 3.4 双 IMU 主备和投票

当前校准槽和优先级：

    CAL_ACC0_ID   = ICM42688P
    CAL_ACC0_PRIO = 75
    CAL_ACC1_ID   = JY901B
    CAL_ACC1_PRIO = 50
    CAL_ACC2_ID   = 0

    CAL_GYRO0_ID   = ICM42688P
    CAL_GYRO0_PRIO = 75
    CAL_GYRO1_ID   = JY901B
    CAL_GYRO1_PRIO = 50
    CAL_GYRO2_ID   = 0

    SENS_IMU_MODE = 1

已确认：

- ICM42688P 被选为当前主加速度计和主陀螺仪。
- JY901B 作为低优先级备份传感器参与选择链路。
- 重复的 CAL_*2_ID 已清理。
- sensor_selection 指向 ICM42688P。

### 3.5 约 30 分钟静止零漂观察

飞控保持静止，约每 30 秒采样一次，共 61 组样本。

| 传感器 | 观察结果 |
|---|---|
| ICM42688P 加速度 | 端点漂移最大约 0.0020 m/s²，全程跨度最大约 0.0107 m/s² |
| ICM42688P 陀螺仪 | 端点变化最大约 0.0003 rad/s，全程跨度约 0.0005 rad/s |
| JY901B 加速度 | 端点漂移最大约 0.0064 m/s²，全程跨度最大约 0.0094 m/s² |
| JY901B 陀螺仪 | 静止采样中长期为 [0, 0, 0]，被 DataValidator 判定为 STALE |
| ICM 温度 | 21.97–22.38 °C |
| JY901B 温度 | 26.42–26.86 °C |

结论：

- ICM42688P 的静止输出稳定，当前适合作为主 IMU。
- JY901B 驱动通信没有异常；陀螺仪持续为零更可能是模块量化/静止自动归零导致，不应直接判定为串口或驱动故障。
- JY901B 的有效静态陀螺仪分辨率和自动归零阈值仍需单独做配置和动态测试。

### 3.6 GPS 和外置磁力计基础检查

- GPS 使用 UBX 协议，/dev/ttyS1，115200 自动检测，位置/速度数据约 8 Hz，数据流新鲜。
- 室内无卫星时 lat/lon 变化属于 GPS 无 fix 时的无效输出，不能作为定位故障判据。
- GPS 模块内置 IST8310 在 I2C1 0x0e 在线，sensor_mag 数据健康，error_count=0。
- 两颗磁力计同时存在时，当前方向和主磁力计选择必须以设备固定后的实测航向为准；室外指北和完整抗干扰闭环仍未完成。

## 4. 固件和参数更新

板级默认值已改为：

    param set-default SENS_JY901_ROT 0

构建检查已通过：

    make gjl_h743mini_default

更新固件后 NSH 实读：

    SENS_JY901_ROT = 0

并显示为已保存参数。当前不需要再执行 param set；如果后续参数被恢复为旧值，应执行：

    param set SENS_JY901_ROT 0
    param save
    reboot
