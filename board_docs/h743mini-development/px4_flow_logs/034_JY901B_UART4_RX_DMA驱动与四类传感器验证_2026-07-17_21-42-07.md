## 任务目标

本轮目标是在 H743mini 上完成 JY901B 串口传感器驱动、UART4 RX DMA 和 PX4 标准传感器链路接入，使模块能够作为副 IMU、磁力计和气压计参与 PX4 传感器框架。

本轮交付范围：

- 通过 `UART4 PH13/PH14`、`/dev/ttyS3` 接收 JY901B 数据。
- 解析 `0x51/0x52/0x54/0x56` 四类 11 字节帧。
- 发布PX4标准 `sensor_accel`、`sensor_gyro`、`sensor_mag`、`sensor_baro` 话题。
- 加速度、角速度、磁场和气压均保持模块实收约 `200 Hz`。
- 启用 UART4 RX DMA，驱动继续使用NuttX普通非阻塞 `read()`。
- 启动时配置模块输出，但不发送 SAVE，不在每次飞控启动时擦写模块 Flash。
- 统一JY901B与ICM42688P的PX4最终坐标系。
- 修复JY901B整数气压在静止时被误判为 `STALE` 的兼容问题。
- 保持默认不自动启动，完成重新校准和优先级验证后再启用。

## 本轮修改内容

### 1. 新增JY901B驱动和独立解析器

新增目录：

```text
src/drivers/imu/jy901b/
```

主要文件：

```text
CMakeLists.txt
Kconfig
module.yaml
JY901B.hpp
JY901B.cpp
JY901B_Parser.hpp
JY901B_Parser.cpp
jy901b_main.cpp
tests/JY901B_ParserTest.cpp
```

命令接口：

```sh
jy901b start -d /dev/ttyS3 -R 0
jy901b status
jy901b stop
```

解析器特性：

- 固定识别 `0x55` 帧头和11字节帧长。
- 校验低8位累加和。
- 支持半帧、连续多帧、前导噪声、错误校验和丢字节后的重同步。
- 解析状态跨多次 `read()` 保留。

### 2. 配置模块运行时输出但不保存Flash

驱动初始化时依次发送：

```text
FF AA 69 88 B5    解锁
FF AA 02 56 00    选择 0x51/0x52/0x54/0x56 输出
FF AA 03 0B 00    设置 200 Hz
```

驱动不发送 SAVE 命令。模块每次飞控启动时由驱动恢复所需运行配置，避免反复擦写JY901B内部Flash。

串口配置固定为：

```text
115200 baud
8 data bits
no parity
1 stop bit
no flow control
```

### 3. 发布四类PX4标准传感器数据

设备类型：

```text
DRV_IMU_DEVTYPE_JY901B  = 0x2C
DRV_MAG_DEVTYPE_JY901B  = 0x2D
DRV_BARO_DEVTYPE_JY901B = 0x2E
```

发布映射：

| JY901B帧 | PX4话题 | 比例和单位 |
|---|---|---|
| `0x51` | `sensor_accel` | `raw / 32768 * 16g`，发布为 `m/s^2` |
| `0x52` | `sensor_gyro` | `raw / 32768 * 2000 dps`，发布为 `rad/s` |
| `0x54` | `sensor_mag` | `1 / 12000 Gauss/LSB` |
| `0x56` | `sensor_baro` | 32位小端整数压力，单位 `Pa` |

JY901B高度仅保存在 `jy901b status` 中，不直接输入EKF2。气压温度填 `NAN`，不把IMU温度伪装成气压芯片温度。

### 4. 启用UART4 RX DMA

板级配置：

```text
UART4_TX = PH13
UART4_RX = PH14
/dev/ttyS3
CONFIG_UART4_BAUD=115200
CONFIG_UART4_RXBUFSIZE=600
CONFIG_UART4_RXDMA=y
DMAMAP_UART4_RX=DMAMAP_DMA12_UART4RX_0
```

驱动运行在 `wq:ttyS3`，继续使用非阻塞 `read()`。DMA缓冲、串口环形缓冲和D-cache一致性由NuttX串口层管理，不在JY901B驱动中重复实现DMA状态机。

板上 `top` 观察到：

```text
PID 858  wq:ttyS3  CPU约1.35%  stack 1192/1632
```

`DMA Memory: 0 used` 只表示PX4动态DMA内存池未使用，不代表NuttX静态UART RX DMA未启用。

### 5. 统一JY901B与ICM42688P坐标

JY901B和ICM42688P原始传感器坐标均按：

```text
X前、Y左、Z上
```

PX4机体系要求：

```text
X前、Y右、Z下（FRD）
```

JY901B驱动现在与ICM42688P驱动采用相同的内部转换：

```text
PX4 X =  raw X
PX4 Y = -raw Y
PX4 Z = -raw Z
```

因此两颗IMU在当前物理安装方向下都使用：

```text
ICM42688P：-R 0
JY901B：   -R 0
```

坐标改变后，旧的JY901B加速度计、陀螺仪和磁力计校准参数不再作为最终结果使用，必须重新校准。

### 6. 定点修复JY901B气压STALE误判

JY901B气压以整数Pa输出，静止时可能连续多帧完全相同。`VehicleAirData` 同时向 `DataValidator` 放入压力和由压力计算的高度，默认相同值计数阈值为100；在约200Hz下会很快误判 `STALE`。

本轮修复策略：

- `DataValidatorGroup` 增加按传感器实例设置相同值阈值的接口。
- 只对 `DRV_BARO_DEVTYPE_JY901B (0x2E)` 将阈值设为 `UINT32_MAX`。
- 非JY901B气压计仍保持默认阈值100。
- 设备ID变化时重新识别设备类型，支持未来热替换成其他气压计后恢复默认检测。
- 相同值计数器在 `UINT32_MAX` 饱和，避免长期200Hz运行发生整数回绕。
- `VehicleAirData` 的 `300 ms` 超时、驱动串口错误和校验错误检测均保持不变。
- 不向气压数据伪造噪声，不降低200Hz发布率。

## 关键输出解释

- 四类 `200.7 Hz`：说明115200波特率下当前四类帧能够持续接收，驱动没有人为降频。
- `read/checksum/timeout = 0`：当前UART、DMA和协议校验链路稳定。
- `Type 0x2C/0x2D/0x2E`：确保accel/gyro、mag、baro校准能够稳定绑定到各自设备类型。
- `BARO state: OK`：整数Pa不再触发JY901B专属误报。
- 停止后 `BARO state: TOUT`：300ms真实超时保护仍然有效。
- `wq:ttyS3`：JY901B是PX4工作队列任务，不会在 `top` 中显示独立的 `jy901b`进程名。
- `SENS_JY901_EN=0`：当前默认不自动启动，避免未重新校准的副传感器参与投票。
