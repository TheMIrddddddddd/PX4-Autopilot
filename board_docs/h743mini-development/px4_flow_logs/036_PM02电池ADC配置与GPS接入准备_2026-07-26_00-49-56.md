## 本轮配置与修改内容

### 1. PM02 模拟电池检测链路已启用

待提交的板级修改已经完成以下配置：

- `default.px4board` 启用 `CONFIG_DRIVERS_ADC_BOARD_ADC=y` 和 `CONFIG_MODULES_BATTERY_STATUS=y`。
- `rc.board_sensors` 启动 `board_adc`。
- `board_config.h` 将 `PC4 / ADC1_INP4` 作为电流通道、`PC5 / ADC1_INP8` 作为电压通道，并纳入 `ADC_CHANNELS`。
- `BOARD_NUMBER_BRICKS` 收口为 `1`，同时补齐 PX4 单电池砖块兼容宏。
- `rc.board_defaults` 写入 PM02 的默认换算参数：

```sh
BAT1_SOURCE=0
BAT1_V_DIV=18.182
BAT1_A_PER_V=36.364
BAT1_N_CELLS=3
BAT1_CAPACITY=5300
```

其中 `BAT1_N_CELLS=3`、`BAT1_CAPACITY=5300` 对应计划使用的 3S 5300 mAh 电池；这些是默认参数，后续可以在 QGroundControl 或 NSH 中校准、保存和修改。

### 2. PM02 接线边界

PM02 接入 H743mini 时按信号名称连接，不根据未核实的插座针序盲接：

| PM02 信号 | H743mini 引脚 | STM32 外设 | 说明 |
|---|---|---|---|
| `5V` | 板级 `5V` 输入 | 供电 | 给飞控逻辑供电，先确认 PM02 的 5.2 V BEC 输出正常 |
| `GND` | `GND` | 地 | 必须与飞控、GPS、接收机、电调共地 |
| `CURR` | `PC4 / P1-19` | `ADC1_INP4` | 电流模拟量 |
| `VOLT` | `PC5 / P1-20` | `ADC1_INP8` | 电压模拟量 |

电池正负极只接 PM02 的电池输入端，不能把电池正极直接接到 `PC5`。接线前先量 `CURR`、`VOLT` 对地电压，确认任何工作状态下都不超过 MCU ADC 的 `3.3 V` 上限。

PM02 给飞控供电时，不应再把未经隔离的 USB `5V` 与 PM02 `5V` 同时并接到同一电源轨；调试时可保留 USB 的数据连接，但必须避免两路 `5V` 互相反灌。

### 3. 未接 PM02 时的板上实测

USB 供电、PM02 未接时，用户已确认：

```text
board_adc status       -> running
battery_status status  -> running
```

`listener adc_report` 的关键输出为：

```text
raw_data: [65535, 65535, 65535, 65535, 0, ...]
resolution: 65536
v_ref: 3.3000
channel_id: [4, 8, 18, 20, -1, ...]
```

通过 USB MAVLink 读取到的假电池状态为：

```text
BAT1_SOURCE       = 0
BAT1_V_DIV        = 18.182
BAT1_A_PER_V      = 36.364
BAT1_N_CELLS      = 3
BAT1_CAPACITY     = 5300

BATTERY_STATUS:
voltage            = 59.999 V
current            = 119.99 A
current_consumed   = 35241 mAh
remaining          = 0 %
```

这不是 USB 供电正在把电池放空，而是未连接的 `PC4/PC5` 浮空后被 ADC 读到接近 `3.3 V`。按当前比例换算后约为 `3.3 * 18.182 = 60 V` 和 `3.3 * 36.364 = 120 A`，所以 PX4 显示错误的低电量状态。

若 PM02 不会马上接入，临时禁用电池源的命令为：

```sh
param set BAT1_SOURCE -1
param save
reboot
```

用户尚未确认执行过上述命令。PM02 正确接入并确认模拟量正常后，再恢复：

```sh
param set BAT1_SOURCE 0
param save
reboot
```

### 5. GPS + IST8310 已具备接线条件

当前板级源码已经启用 GPS 驱动并将 GPS1 设为 `/dev/ttyS1`：

```text
CONFIG_BOARD_SERIAL_GPS1="/dev/ttyS1"
CONFIG_DRIVERS_GPS=y
```

`board.h` 的当前真实复用为：

```text
GPIO_USART2_RX = PA3
GPIO_USART2_TX = PA2
```

按用户选定的 M9 GPS + IST8310 组合，模块接线关系为：

| 模块信号 | H743mini 引脚 | 说明 |
|---|---|---|
| GPS `TX` | `PA3 / USART2_RX` | 模块发，飞控收 |
| GPS `RX` | `PA2 / USART2_TX` | 飞控发，模块收 |
| IST8310 `SDA` | `PB7 / I2C1_SDA` | 外置罗盘数据 |
| IST8310 `SCL` | `PB8 / I2C1_SCL` | 外置罗盘时钟 |
| `GND` | `GND` | 必须共地 |
| `VCC` | 按模块实物规格确认 | 模块电源和 UART/I2C 电平尚未由实物标签复核，不能仅凭通用接法猜定 |

GPS 接入后设置并验证：

```sh
param set GPS_1_CONFIG 201
param set GPS_1_PROTOCOL 1
param set SER_GPS1_BAUD 0
param save
reboot

gps status
listener sensor_gps
```

外置 IST8310 先在未固定安装方向的条件下探测，不直接沿用旧的 `-R 10`：

```sh
i2cdetect -b 1
ist8310 -X -b 1 -R 0 start
ist8310 status
listener sensor_mag
```

预期 IST8310 I2C 地址为 `0x0e`。确认模块实际安装方向后，再进行罗盘校准并保存方向参数。

## 当前结论

- **可以开始接入 GPS 与 PM02。** GPS 的 `USART2 PA2/PA3`、外置 IST8310 的 `I2C1 PB7/PB8`、PM02 的 `PC4/PC5` ADC 引脚和启动链路均已具备。
- PM02 软件配置已经构建通过，且 `board_adc` 与 `battery_status` 在板上运行；未接 PM02 时的 `60 V / 120 A / 0%` 是浮空 ADC 造成的假数据，不是电池或 USB 的真实掉电。
- GPS 驱动已编入固件，但 GPS 与 IST8310 还没有实物通信、定位、罗盘读数或校准证据；PM02 同样尚未验证真实电压、电流和容量估算。
- 风险等级：**潜在风险**。接线前需确认模块实际 `VCC`、连接器针序和逻辑电平；PM02 供电时必须避免 USB 与 PM02 的 5V 电源反灌。

## 下一阶段任务和目标

目标：按已确认的 MCU 引脚完成 PM02 与 GPS + IST8310 的物理接入，在不装桨、无电调大电流负载的条件下完成电池与定位/罗盘的最小闭环验证。

优先任务：

1. 先核对 PM02 和 GPS 模块实物丝印、连接器针序、允许供电范围和 UART/I2C 电平；先接 `GND`，再接信号线。
2. PM02 接入前量 `5V`、`CURR`、`VOLT`，确认 `CURR/VOLT` 都不超过 `3.3 V`；由 PM02 供电时避免 USB 5V 并联反灌。
3. 用 3S 电池接入 PM02 后，检查 `listener adc_report` 和 `listener battery_status`：静置电压应在 3S 合理范围，电流不应再固定为约 `120 A`，剩余电量不应固定为 `0%`。
4. 接入 GPS 后配置 `GPS_1_CONFIG=201`，检查 `gps status` 与 `sensor_gps`；在开阔天空等待有效定位，不把室内无定位直接判断为串口失败。
5. 使用 `i2cdetect -b 1` 确认 IST8310 地址 `0x0e`，启动驱动并检查 `sensor_mag`，随后在 QGroundControl 完成电池、罗盘和传感器校准。

验收标准：

- PM02 的 `battery_status` 显示可信 3S 电压、近零静置电流和非固定的剩余电量，且 QGroundControl 可显示并允许后续校准参数。
- GPS 串口持续收到有效数据，`sensor_gps` 更新；IST8310 能被 I2C 扫描到并发布磁力计数据。
- 接线、参数、实测输出和任何异常均写入下一份进展日志；在 GPS、罗盘、电池均校准前，不进入带桨或实际飞行验证。
