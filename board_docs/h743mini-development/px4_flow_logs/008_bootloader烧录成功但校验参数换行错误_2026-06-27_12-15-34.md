# 008 bootloader 烧录成功但校验参数换行错误 2026-06-27 12:15:34

## 概念
本次进展是通过 STM32CubeProgrammer CLI 成功将 `gjl_h743mini_bootloader.bin` 写入 STM32H743 内部 Flash 起始地址 `0x08000000`。命令最后的 `-v` 因换行写法问题被 shell 当作单独命令执行，因此本次写入成功但未执行校验。

## 代码/流程
### 已执行命令
用户执行了 bootloader 写入命令，目标地址为：

```text
0x08000000
```

### 关键输出
```text
SWD freq    : 950 KHz
Connect mode: Under Reset
Device ID   : 0x450
Device name : STM32H7xx
NVM size    : 2 MBytes

Opening and parsing file: gjl_h743mini_bootloader.bin

Memory Programming ...
  File          : gjl_h743mini_bootloader.bin
  Size          : 44.56 KB
  Address       : 0x08000000

Erasing internal memory sector 0
Download in Progress:
[==================================================] 100%

File download complete
Time elapsed during download operation: 00:00:01.865
-v：未找到命令
```

### 当前判断
- `File download complete` 表示 bootloader 已经写入完成。
- `-v：未找到命令` 不是 CubeProgrammer 报错，而是 shell 把 `-v` 当成单独命令执行。
- 本次没有完成 verify 校验，建议下一步单独执行 verify，或者在 app 烧录时注意把 `-v` 放在同一条命令中。

## 常见坑
- 反斜杠 `\` 必须放在一行末尾，并且后面不能有空格。
- 不要单独一行只写 `\`。
- 不要在续行中间插入空行，否则下一行参数会变成新的 shell 命令。

## 调试方法
建议下一步单独校验 bootloader：

```bash
STM32_Programmer_CLI -c port=SWD mode=UR reset=HWrst freq=1000 \
  -v build/gjl_h743mini_bootloader/gjl_h743mini_bootloader.bin 0x08000000
```

然后烧录 app：

```bash
STM32_Programmer_CLI -c port=SWD mode=UR reset=HWrst freq=1000 \
  -w build/gjl_h743mini_default/gjl_h743mini_default.bin 0x08020000 \
  -v -rst
```

## 复盘要点
- bootloader 写入已经成功。
- 当前只缺少 verify 校验。
- 后续命令续行要保持每一行末尾的 `\` 直接连接下一行参数。
