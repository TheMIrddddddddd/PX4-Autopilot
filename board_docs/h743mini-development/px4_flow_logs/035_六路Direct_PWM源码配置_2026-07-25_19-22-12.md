## 本轮修改内容

### 1. Direct PWM 输出从八路收口为六路

`boards/gjl/h743mini/src/board_config.h` 中的定义已变更为：

```c
#define DIRECT_PWM_OUTPUT_CHANNELS   6
#define BOARD_NUM_IO_TIMERS 2
```

这与 `timer_config.cpp` 中两个 `io_timer` 和六个 PWM 通道一致。原 FMU-v6C 风格的八路 `TIM1/TIM4/TIM5` 映射不再是 H743mini 的 Direct PWM 配置。

### 2. 当前六路定时器和引脚映射

`boards/gjl/h743mini/src/timer_config.cpp` 当前配置：

| PX4 输出角色 | 引脚 | 定时器通道 | 说明 |
|---|---|---|---|
| `MAIN1 / M1` | `PA15` | `TIM2_CH1` | 原 Brick1 valid GPIO 已不初始化 |
| `MAIN2 / M2` | `PB3` | `TIM2_CH2` | 使用时不能同时使用 SWO/SWV trace |
| `MAIN3 / M3` | `PB10` | `TIM2_CH3` | 不再与 I2C2 冲突 |
| `MAIN4 / M4` | `PB11` | `TIM2_CH4` | 不再与 I2C2 冲突 |
| `MAIN5 / AUX1` | `PB4` | `TIM3_CH1` | 待确认实际排针位置和波形 |
| `MAIN6 / AUX2` | `PB5` | `TIM3_CH2` | 不能与未来的 `CAN2_RX` 同时使用 |

`TIM2` 配置了 `DMA{DMA::Index1}`，`TIM3` 未配置 DShot DMA。当前代码中的 `MAIN5 / AUX1`、`MAIN6 / AUX2` 是输出角色标注；某一路最终用于 MAIN 还是 AUX，由 PX4 的 mixer/actuator 配置决定，不是两套同时存在的引脚。

### 3. NuttX TIMx 配置的真实约束

早期文档把“使用 `TIM2`”写成“需要启用 `CONFIG_STM32H7_TIM2=y`”。读取当前 PX4 H7 架构代码后，该结论需要更正：Direct PWM 使用的是 PX4 `io_timer`，不是 NuttX 通用 PWM/timer 驱动。

`platforms/nuttx/src/px4/stm/stm32h7/include/px4_arch/io_timer_hw_description.h` 中，`initIOTimer()` 对每个 Direct PWM timer 都有编译期检查：

```cpp
constexpr_assert(!nuttx_config_timer_enabled,
                 "IO Timer requires NuttX timer config to be disabled (STM32_TIMx)");
```

同一代码为 `TIM2` 和 `TIM3` 提供了寄存器基址、RCC 使能位、时钟频率和中断向量。`io_timer_init_timer()` 会直接使能 RCC、初始化定时器寄存器并安装中断，因此不应为了 Direct PWM 额外打开 NuttX 的 `TIM2` 或 `TIM3` 配置。

本提交在 `defconfig` 中删除：

```text
CONFIG_STM32H7_TIM1=y
CONFIG_STM32H7_TIM4=y
CONFIG_STM32H7_TIM5=y
```

这与 Direct PWM 不再使用 `TIM1/TIM4/TIM5` 一致。`TIM12` 保留给已经验证的 `tone_alarm -> PB14` 蜂鸣器链路，不属于这六路 Direct PWM。

### 4. 复用关系复核

- `PA15`：原 FMU-v6C 的 `GPIO_nPOWER_IN_A`。当前 `BOARD_ADC_BRICK1_VALID` 固定为有效，且 `PA15` 已从 `PX4_GPIO_INIT_LIST` 排除，可供 `TIM2_CH1` 使用。
- `PB3`：可复用为 SWO/SWV trace。当前保留的四针 SWD 下载只使用 `PA13/SWDIO` 和 `PA14/SWCLK`，PWM 与 SWO/SWV 不能同时使用。
- `PB10/PB11`：当前 I2C2 已迁移到 `PH4/PH5`，不再占用这两路 `TIM2` 输出。
- `PB5`：`board.h` 仍保留 `GPIO_CAN2_RX` 候选定义。当前 CAN GPIO 初始化已屏蔽，`CONFIG_DRIVERS_UAVCAN=n`；未来若恢复 CAN2，必须迁移 PWM6、迁移 CAN2 或放弃其中一项。
- `PB14`：蜂鸣器使用 `TIM12_CH1`，与 `TIM3_CH1/CH2` 没有定时器或引脚冲突。

## 修改和验证流程

### 第一步：提交和源码一致性检查

已读取最近提交完整 diff，并核对以下关系：

```text
DIRECT_PWM_OUTPUT_CHANNELS = 6
BOARD_NUM_IO_TIMERS       = 2
io_timers                 = TIM2, TIM3
timer_io_channels         = 6
```

结论：数量关系一致，没有保留多余的 V6C Direct PWM timer 描述。

### 第二步：引脚复用和 AF 配置检查

H743 `io_timer` 对 `TIM2` 自动选择 AF1，对 `TIM3` 自动选择 AF2。NuttX H743 pinmap 中存在与当前配置一致的输出复用：

```text
PA15 -> TIM2_CH1OUT / AF1
PB3  -> TIM2_CH2OUT / AF1
PB10 -> TIM2_CH3OUT / AF1
PB11 -> TIM2_CH4OUT / AF1
PB4  -> TIM3_CH1OUT / AF2
PB5  -> TIM3_CH2OUT / AF2
```

该检查只证明 MCU 复用和当前源码描述相符，不证明最小系统板排针、外接电调、电平和实际波形已经通过验收。

### 第三步：验证边界

本轮没有重新执行：

```text
make gjl_h743mini_default
make gjl_h743mini_default upload
```

也没有新的串口、`pwm info`、示波器、逻辑分析仪或电调测试输出。因此不能把本轮记录表述为“六路 PWM 已上板可用”。此前 JY901B 阶段的 FLASH 使用率和蜂鸣器有声结果也不能作为六路 PWM 的验证依据。

## 关键输出解释

- `DIRECT_PWM_OUTPUT_CHANNELS = 6`：PX4 板级 Direct PWM 对外声明六个输出通道。
- `BOARD_NUM_IO_TIMERS = 2`：六个通道由两组独立的计数器 `TIM2`、`TIM3` 管理，两个定时器可以使用不同的 PWM rate。
- `TIM2_CH1~CH4`：四路主电机候选输出，保留原先统一于 TIM2 的四旋翼规划。
- `TIM3_CH1~CH2`：新增第五、第六输出；其最终角色由 PX4 输出配置决定。
- NuttX `TIMx` 配置保持关闭：这是 PX4 `io_timer` 的编译期约束，不是遗漏 `TIM2/TIM3` 配置。
- `PB5 / CAN2_RX`：当前未冲突的前提是 CAN2 没有启用；这是一项未来扩展约束，不是已完成的 CAN2 适配。

## 当前结论

- 六路 Direct PWM 的板级源码配置已经完成：`TIM2` 提供 `PA15/PB3/PB10/PB11` 四路，`TIM3` 提供 `PB4/PB5` 两路。
- `DIRECT_PWM_OUTPUT_CHANNELS`、`BOARD_NUM_IO_TIMERS`、`io_timers` 和通道数组的数量一致。
- NuttX 通用 `TIMx` 驱动应保持关闭，Direct PWM 由 PX4 `io_timer` 直接控制；旧文档中“启用 TIM2”的建议已在主文档中更正。
- `PB3` 与 SWO/SWV、`PB5` 与潜在 CAN2 是明确的复用约束；蜂鸣器 `PB14/TIM12` 不与新 PWM 组冲突。
- 风险等级：**潜在风险**。当前没有本轮编译、烧录和硬件波形证据，不能确认六路输出的实际频率、顺序、电平或电调兼容性。

## 下一阶段任务和目标

目标：在不装桨的条件下，完成六路 Direct PWM 从构建、烧录到实板波形和输出顺序的闭环验证。

优先任务：

1. 执行 `make gjl_h743mini_default`，保存完整构建结果、FLASH 使用率和任何 timer 相关 warning。
2. 烧录后通过已确认可用的 USB/QGC 与 CH340/NSH 调试链路，确认 PWM 模块识别到六个 Direct PWM 输出。
3. 先不接电调或不装桨，使用示波器或逻辑分析仪分别测量 `PA15/PB3/PB10/PB11/PB4/PB5` 的频率、脉宽和输出顺序。
4. 在确认波形正常后，再逐路连接电调信号线和地线，使用 QGroundControl 的 Actuator Test 验证 M1 至 M6 顺序；电调供电不从 MCU GPIO 获取。
5. 若要启用 CAN2，先重新分配 `PB5` 的 PWM6/CAN2_RX 冲突，再修改任何 CAN 配置。
6. 根据原理图补齐 `PB4/PB5` 的实际排针位置和外接接口定义，不把 MCU 管脚名直接当作已可接出的接口。

验收标准：

- `make gjl_h743mini_default` 通过，且没有 `timer_config.cpp`、`io_timer` 或资源冲突错误。
- 固件启动后能确认六个 Direct PWM 通道被识别，没有与蜂鸣器、HRT、RC 输入或已启用外设的资源冲突。
- 六个引脚均测得稳定、正确的 PWM 波形，输出顺序与 actuator test 一致。
- 全程不装桨；仅在单路、低风险验证完成后才连接电调。
- 主文档补齐实测结果、构建输出和任何最终引脚调整后，才把当前状态从“源码已配置”更新为“上板已验证”。
